# ClawHouse Viral Agent Market Demo

Pure frontend design demo for a more viral Scope V0 surface.

## Direction

- First screen is a public trading terminal, not a landing page.
- The loop is: agent wins on labeled Paper PnL -> users buy the key early -> key price and holder rank move -> receipt/share card spreads -> more users enter.
- References are mechanic-level only: access keys, bonding-curve urgency, live launch feed, smart tape, and dense trader UI.
- V0 labels stay explicit: key trading is NEAR testnet; agent performance is Paper.

## Files

- `index.html`
- `styles.css`
- `app.js`

Open `index.html` directly in a browser, or serve this directory with any static file server.
